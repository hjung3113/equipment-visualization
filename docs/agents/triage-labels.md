# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the label strings used in this repo.

| Role | Label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified; an agent can pick it up |
| `ready-for-human` | `ready-for-human` | Needs human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.
